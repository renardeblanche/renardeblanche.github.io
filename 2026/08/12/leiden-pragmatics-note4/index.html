1. 关联理论的基本定位

1.1 什么是关联理论？

关联理论（Relevance Theory, RT）由 Dan Sperber 与 Deirdre Wilson 提出，是一种关于人类认知与交流（cognition and communication）的语用学理论。

它并不主要研究“语言系统本身如何运作”，而更关注：

人们如何利用语言和其他刺激进行交流，以及听者如何在具体语境中推断交际者想要传达什么。

因此，RT 是一套广义的交流理论（theory of communication），不仅适用于语言刺激，也适用于非语言和多模态刺激。

课件特别强调：

  • RT 不把意义简单等同于对世界作出一个可真假的描述；
  • 交际者和理解者会从环境中的信息获得认知效果；
  • 得到一个可进行真假判断的 proposition 是理解过程中的重要一步，但并不是整个交际理论的终点。

1.2 与 Grice 的关系

关联理论继承了 Grice 的几个核心洞见：

  1. 交流是一种意图性的活动；
  2. 理解语言不仅依靠解码（decoding），还依靠推断（inference）；
  3. 听者会思考说话者为什么这样说；
  4. relevance（相关性）在理解中具有重要作用。

但 RT 并不是简单地把 Grice 的 Relation Maxim: “Be relevant” 提升为最高准则。

更准确地说：

Sperber 和 Wilson 将 Grice 关于 relevance 的洞见重新概念化为关于人类认知和交际的一般原则。

Grice 的 maxims 更像是可以用来理性重构交际推理的原则；RT 的原则则被描述为：

generalisations about cognition and communication

即对人类认知和交流实际如何运作的概括，而不是“我们应该努力遵守”的规范。

2. 相关性：认知效果与处理努力

2.1 Relevance 的两个维度

关联理论从两个因素理解相关性：

Cognitive effects（认知效果）

一个刺激或解释使我们的认知环境发生有价值变化。

Processing effort（处理努力）

为了注意、理解和推断这个刺激所需要投入的认知资源，包括：

  • 时间；
  • 注意力；
  • 工作记忆；
  • 长期记忆检索；
  • 推理资源等。

需要注意：RT 通常并不把 relevance 当作可以简单精确计算的数学数值，而主要作比较性理解。

2.2 三类典型认知效果

1. Strengthening an existing assumption

强化已有假设

新信息支持原本已经存在的判断。

例如：

  • 你听见撞击声，怀疑外面发生了车祸；
  • 随后看到两辆车撞在一起；
  • 新信息强化了原来的假设。

2. Eliminating / contradicting an assumption

排除或否定错误假设

新信息与原来的假设冲突，使我们放弃原来的判断。

例如：

  • 你以为撞击声来自车祸；
  • 后来发现只是垃圾车撞到了垃圾桶；
  • 原先的假设被排除。

3. Deriving contextual implications

推出新的语境蕴涵 / 语境推论

将新信息和已有的 contextual assumptions 结合，推出此前无法单独推出的新结论。

例如：

外面发生严重车祸
+ 严重车祸可能造成人员受伤
→ 可能有人需要医疗救助。

这类由新信息 + 已有背景假设共同推出的新结论，是 RT 中非常重要的 cognitive effect。

2.3 Relevance 是相对于个人的

相关性不是完全客观固定的。

因为不同人拥有：

  • 不同背景知识；
  • 不同经验；
  • 不同兴趣；
  • 不同当前目标；
  • 不同可及的 contextual assumptions；

所以同一个 stimulus 对不同人的：

  • cognitive effects；
  • processing effort；

都可能不同。

因此：

Relevance is relevance to an individual.

这解释了为什么相同的话语可能对不同听者产生完全不同的解释和意义。

3. 两个关联原则

3.1 Cognitive Principle of Relevance

认知关联原则

核心思想：

The human cognitive system is geared towards the maximisation of relevance.

即：

人类认知系统整体倾向于最大化相关性。

我们的认知资源是有限的，不可能同时处理世界上的所有刺激。

因此，人们会倾向于把：

  • 注意力；
  • 推理资源；
  • 记忆检索资源；

投入到预期能带来较高认知效果、同时不需要不必要处理努力的信息上。

这里的 maximisation of relevance 不应简单理解为：

“获得的信息越多越好”。

因为大量信息如果需要巨大处理成本，却不能带来相应认知收益，就未必高度 relevant。

3.2 Communicative Principle of Relevance

交际关联原则

核心表述：

Every act of ostension communicates a presumption of its own optimal relevance.

即：

每一个明示行为（ostensive act）都会产生一种关于自身最优相关性的预期。

当某人故意吸引我们的注意时，我们自然会假设：

“对方既然特意让我注意这个东西，那么理解它应该是值得的。”

3.3 Maximal relevance 与 optimal relevance 的区别

这两个概念不要混淆。

Maximal relevance

主要与 Cognitive Principle 有关：

认知系统总体倾向于最大化相关性。

Optimal relevance

主要与 Communicative Principle 有关：

一个 ostensive stimulus 使听者期待：存在一个足以证明其处理努力是值得的解释。

因此，optimal relevance 并不要求听者找到理论上所有可能解释中“绝对最相关”的那个解释。

实际理解通常是：

找到一个足以满足 relevance expectations 的解释，然后停止继续搜索。

这使 RT 的理解模型具有明显的 satisficing（满足即可停止）特征，而不是穷尽所有可能解释。

4. Ostension 与 ostensive-inferential communication

4.1 Ostension：明示

Ostension（明示）指：

有意把他人的注意力引向某个刺激，同时使自己的交际意图显现出来。

例如：

  • 说一句话；
  • 指向某个物体；
  • 故意做一个手势；
  • 把某张图片展示给别人；
  • 在特定语境中故意制造某个引人注意的行为。

因此：

Speaking is an act of ostension.

话语本身就是一种 verbal ostensive stimulus。

4.2 Ostensive-inferential communication

关联理论把典型的人类意图性交际称为：

ostensive-inferential communication（明示—推理式交际）

它有两个互补方向：

Speaker / Communicator 一侧：ostension

说话者通过某个刺激，使听者意识到：

“我希望你注意并理解这个刺激。”

Hearer / Addressee 一侧：inference

听者认识到这个行为是有意交际，因此开始推断：

“为什么对方要让我注意这个？”
“对方希望我理解什么？”

4.3 与 Grice 的 MeaningNN

这一点直接继承了 Grice 关于 non-natural meaning（MeaningNN） 的思想。

理解一个交际行为，不只是：

S 的行为使 H 得到信息 P。

更重要的是：

H 之所以得到 P，是因为 H 认识到 S 想让 H 得到 P。

也就是说，speaker's intention 是：

intended to be recognised as intended

因此，交际意图本身必须具有一定程度的公开性 / 可识别性。

4.4 Mutual cognitive environment

相互认知环境

交际发生时，双方各自具有自己的 cognitive environment（认知环境）。

交际可以改变双方共有、并相互显现的认知假设。

这一交集可以理解为：

mutual cognitive environment（相互认知环境）

因此，成功交流不是简单地把“信息包”从一个人的大脑传到另一个人的大脑，而是在互动过程中改变参与者之间共享、可相互识别的认知环境。

5. 非明示刺激与说话者无意推论

并不是听者从某个人身上推出来的所有信息，都属于 speaker meaning 或 implicature。

例如：

  • 一个人的口音透露其地域背景；
  • 声音状态可能透露疲惫或紧张；
  • 无意识的表情可能让别人判断其情绪；
  • 某些行为可能暴露说话者并不想公开的信息。

这些 inference 的特点是：

  1. 说话者未必希望听者得到这些信息；
  2. 说话者未必希望这种意图被识别；
  3. 有时说话者甚至希望听者不要发现。

因此需要区分：

communicated inference
与
speaker-unintended inference

一个非常重要的结论是：

Not everything a hearer infers from an utterance is an implicature.

经典 Grice 和 RT 主要处理 intentional / ostensive communication；说话者无意造成的推论构成了理论边界上的一个重要问题。

6. 关联理论的理解启发式

6.1 Relevance-theoretic comprehension heuristic

关联理论提出一种理解策略：

按照可及性（accessibility）顺序考虑解释，沿着最省处理努力的路径寻找认知效果；当期待的相关性得到满足时停止。

听者可能需要同时处理：

  • disambiguation（消歧）；
  • reference assignment（指称确定）；
  • indexical resolution；
  • enrichment（充实）；
  • contextual assumptions；
  • explicatures；
  • implicatures。

6.2 Accessibility：可及性

一个 interpretation 越容易被迅速调取，就越 accessible。

影响 accessibility 的因素包括：

  • 当前话题；
  • 前文；
  • 当前物理环境；
  • 刚刚被激活的概念；
  • 个人背景知识；
  • 社会文化知识；
  • 说话者与听者之间的共同经验。

因此，听者并不会平等地检查所有逻辑可能的解释。

而是：

最容易想到的解释先被处理。

7. Context 不是固定输入，而是理解过程中的变量

这是 RT 与许多直觉式 context 观念的一个重要区别。

Sperber 和 Wilson 的核心思想可以概括为：

relevance is treated as given, and context is treated as a variable.

也就是说：

听者不是先拥有一个封闭、完整、固定的 context，然后在其中计算意义；而是在解释过程中不断选择最容易获得、最可能产生足够认知效果的 contextual assumptions。

因此，context selection 本身就是理解过程的一部分。

8. 一个典型例子：Dani 去银行了吗？

Adam: Has Dani paid you back yet?
Bella: She didn't make it to the bank today.

听者可能依次处理：

  1. she 最容易被解析为 Dani；
  2. bank 在当前语境中最容易被理解为金融机构；
  3. “没有去银行”与“有没有还钱”的问题相关；
  4. 推断 Dani 很可能没有还钱。

因此可以得到：

Dani has probably not paid Bella back.

如果 Adam 还知道：

  • Bella 一直认为 Dani 不可靠；
  • Dani 经常找借口；

那么这些假设如果高度 accessible，Adam 还可能进一步得到：

Bella is annoyed with Dani.
Bella thinks Dani is making excuses.

这说明：

不同听者或不同认知环境可以使同一句话产生不同层次的认知效果。

9. Explicature：外显义

9.1 为什么需要 explicature？

Grice 的 what is said 通常只允许较有限的语用参与，例如：

  • disambiguation；
  • reference assignment。

RT 认为，确定说话者明确传达的 proposition 往往需要更多语用推断。

因此提出：

explicature（外显义）

9.2 Explicature 的严格定义

课件把 explicature 概括为：

decoded linguistic material + pragmatic inference

也就是：

通过解码和推断共同获得、并构成 utterance logical form 发展结果的 communicated assumption。

而 implicature 则是：

完全通过 inference 得出的独立 proposition。

9.3 Basic-level explicature

基本层外显义

Basic-level explicature（BLE）：

说话者所交际的、能够进行真假判断的基本 proposition。

它已经包含 contextual information，并不等于一个脱离语境的纯语言语义表示。

例如：

Fortunately, Mary is coming.

BLE：

Mary is coming.

9.4 Higher-level explicature

高层外显义

一个 basic-level explicature 还可以嵌入：

  • 说话者态度；
  • speech act description；
  • epistemic attitude；
  • evaluation；

从而形成 higher-level explicature。

例如：

Fortunately, Mary is coming.

BLE：

Mary is coming.

HLE：

It is fortunate that [Mary is coming].

如果前文是：

Is there someone who can help with this problem?

还可能得到 implicature：

Mary can help with this problem.

因此：

层级 内容
Basic-level explicature Mary is coming
Higher-level explicature It is fortunate that Mary is coming
Implicature Mary can help with the problem

10. Explicature 中的语用充实

10.1 省略与未编码内容

例如：

I can if you want me to.

仅靠编码内容无法确定：

  • I 是谁；
  • you 是谁；
  • can 做什么；
  • want me to 做什么。

但在具体语境中，听者可以迅速补足这些内容，形成完整 proposition。

10.2 “John plays well”

John plays well.

理解时需要确定：

  • 哪个 John；
  • play 在这里是什么意思；
  • 玩什么 / 演奏什么。

如果当前正在看 John 拉小提琴，可能形成 explicature：

John plays the violin well.

其中 the violin 并没有直接由原句编码，但属于明确交际 proposition 的组成部分。

10.3 因果关系的充实

Adam: How was the party?
Bella: There wasn't enough drink and everyone left early.

听者可能理解为：

派对上的酒精饮料不够，因此参加派对的人都提前离开。

这里的：

  • drink → alcoholic drink；
  • everyone → everyone at the party；
  • 两事件之间的因果关系；

都依赖 pragmatic enrichment。

这说明：

语境并不只在 proposition 形成之后添加 implicature；语境已经参与显性 proposition 本身的构建。

11. Concept adjustment：概念调整

11.1 为什么需要概念调整？

RT 认为，词典中编码的 lexical meaning 往往具有一定程度的：

underspecification（不充分确定性）

在实际交际中，人们会根据 relevance 对概念进行语用调整。

这种过程称为：

concept adjustment / lexical pragmatics

也就是：

relevance-driven inference 可以进入 lexical meaning 的确定过程，使词汇概念适应具体语境。

11.2 “Boys will be boys”

从纯形式逻辑看：

Boys will be boys.

似乎只是：

[ BOYS = BOYS ]

属于 tautology，几乎不会带来新的认知效果。

但现实中它可以表达很多不同内容，例如：

  • 男孩总会调皮；
  • 男孩总爱打架；
  • 男孩总会在女孩面前逞强；
  • 雄性动物总会为了雌性竞争；
  • 男性总免不了惹麻烦。

因此，听者实际处理的并不是完全相同的字典概念，而是根据 context 调整后的概念。

RT 常用星号表示：

BOY*

11.3 Narrowing 与 broadening

Narrowing（缩窄）

词的临时概念比词典概念范围更小。

例如：

BOY → BOY*

其中 BOY* 可能表示：

“具有某种典型顽皮、爱冒险行为的男孩”。

Broadening（扩展）

词的临时概念比严格字典意义覆盖更广。

例如某些语境中 boys 可能泛指：

  • 成年男性；
  • 雄性动物；
  • 某种具有典型“男性行为”的主体。

因此：

concept adjustment 是 RT 处理 pragmatic intrusion into lexical meaning 的重要机制。

12. Conceptual meaning 与 procedural meaning

12.1 Conceptual meaning

概念意义

概念意义提供进入 utterance representation 的内容，即：

what is represented / what is inferred

例如：

  • vegan；
  • carnivore；
  • food；
  • eat；
  • spicy。

它们激活相应概念。

12.2 Procedural meaning

程序意义

程序意义不主要贡献一个新的概念，而是：

指导、约束或引导听者如何进行推断。

也就是：

how the interpretation is inferred

典型例子：

Calum is vegan but he loves spicy food.

but 不只是增加一个新的对象概念，而是引导听者：

寻找两个分句之间的 contrast。

例如听者可能访问某种预期：

vegans are not expected to like spicy food

然后把第二分句理解为对这一预期的反转或对比。

因此：

Meaning 主要作用
Conceptual meaning 提供 representational content
Procedural meaning 约束 / 指导 inference

12.3 RT 为什么不采用 conventional implicature？

RT 不认为需要保留 Grice 式的 conventional implicature 类别。

因为：

如果某些表达式的语言意义作用主要是指导推断，那么可以把它们分析为 procedural meaning，而不必另设一种“语言编码但又叫 implicature”的意义类型。

因此：

conventional-implicature-like effects → procedural meaning

是 RT 的一种典型重新分析。

13. RT 对 GCI / PCI 区分的态度

Neo-Gricean pragmatics 通常区分：

  • Generalized Conversational Implicature (GCI)
  • Particularized Conversational Implicature (PCI)

RT 不认为这必须是两种本质上不同的推断机制。

RT 的理解过程始终是：

当前 utterance + 当前 context
→ 按 accessibility 处理候选解释
→ 找到足以满足 relevance expectations 的解释

因此，所谓“通常情况下经常出现”的 implicature 和高度依赖特殊语境的 implicature，都可以由同一个 relevance-guided mechanism 解释。

换句话说：

RT 倾向于把 implicature 看成局部、语境敏感的推断，而不是先产生 context-free default，再额外取消。

14. Higher-level explicature 与 irony

14.1 归属与态度

Higher-level explicature 可以表示说话者：

  • 相信某 proposition；
  • 怀疑某 proposition；
  • 对某 proposition 感到高兴；
  • 把某 proposition 归属于另一个人；
  • 与某 proposition 保持距离。

14.2 讽刺

例如：

Adam: He's really reliable.
Bella: Wow! He IS reliable!

如果现实中那个人确实可靠，Bella 可以是在认同 Adam。

但如果双方都知道那个人非常不可靠，那么相同表面形式可以被理解为 irony。

RT 式分析关注：

Bella echo / attribute 了“他很可靠”这一想法，但通过语境和态度与它保持距离。

类似：

What lovely weather!

如果外面正在下大雨，说话者并不一定是在字面断言天气好，而是在 echo 某种“天气很好”的评价并显示否定或疏离态度。

15. Limiting interpretations：为什么不会无限解释？

RT 面临一个重要问题：

如果 utterance 能在很多 context 中产生很多推论，为什么听者不会无限搜索？

答案来自：

  1. accessibility；
  2. path of least effort；
  3. stop when relevance expectations are satisfied。

15.1 “There’s a big cat outside”

cat 可以严格指普通家猫，也可以在 zoological sense 中包括：

  • tiger；
  • lion；
  • leopard 等大型猫科动物。

假设外面真的有一只老虎。

“有老虎”显然可能产生非常强烈的 cognitive effects：

  • 有危险；
  • 需要撤离；
  • 需要报警。

从效果上甚至比“有一只大猫”更加 relevant。

但是一般情况下，听者仍首先进入：

domesticated cat

这一高可及解释。

如果这个解释已经满足 relevance expectations，听者就会：

stop

而不会为了寻找一个“可能产生更大效果”的解释继续枚举所有可能意义。

因此：

optimally relevant interpretation ≠ theoretically maximal-effect interpretation

16. 额外处理努力为什么会产生额外意义？

比较：

How are you?

和：

How are you these days?

通常第二句会被理解为：

说话者对听者近来的状态有更持续、更具体的兴趣。

但 these days 在很多情况下并没有简单改变“问题发生的时间”。

RT 的解释是：

these days 增加了 processing effort。

如果额外语言材料并没有产生相应效果，它会显得没有必要。

因此听者寻找 additional cognitive effects，例如：

speaker is showing greater personal interest in my wellbeing.

可以总结为：

extra processing effort creates an expectation of extra cognitive effects.

17. Repetition、weak implicatures 与 poetic effects

重复会增加 processing effort：

There were houses, houses everywhere.
There's a fox, a fox in the garden.
My childhood days are gone, gone.

听者因此会寻找额外认知效果。

不同语境中可能产生：

  • 数量加强；
  • surprise；
  • emphasis；
  • emotional attitude；
  • nostalgia；
  • sadness；
  • sense of loss 等。

其中有些解释并不是一个非常明确、单一、可清楚写出的 proposition。

RT 把这些较弱、边界不清、说话者责任程度较低的推论称为：

weak implicatures（弱含义 / 弱推论）

大量 weak implicatures 共同产生的开放式解释效果可以称为：

poetic effects（诗性效果）

注意：

poetic effects 不只存在于诗歌。

任何能够引发大量较弱可能解释、而难以确定唯一明确意义的 utterance，都可能产生 poetic effects。

19. 关联理论的主要优势

19.1 把 cognition 与 communication 连接起来

RT 不只提供一个“如何从一句话推出 implicature”的规则，而试图解释：

为什么人类会把有限认知资源投入某些刺激和解释。

19.2 统一解释多种语用过程

同一个 relevance-guided mechanism 可以参与：

  • reference assignment；
  • disambiguation；
  • enrichment；
  • explicature construction；
  • contextual assumption selection；
  • implicature derivation；
  • concept adjustment。

19.3 更充分解释 explicit content 的语用性

RT 强调：

语用推断不是在完整 proposition 形成之后才开始。

很多 context-sensitive inference 已经进入 explicature 的构建过程。

19.4 能够解释不同听者的解释差异

因为：

relevance is individual-relative

所以：

不同 cognitive environments
→ 不同 accessible assumptions
→ 不同 processing cost
→ 不同 optimally relevant interpretation。

19.5 能处理开放、弱确定的意义

通过：

  • weak implicatures；
  • poetic effects；

RT 可以描述一些并非单一清楚 proposition 的交际效果。

20. 理论边界与批评

Billy Clark 在本章最后提出了两个特别值得注意的批评方向。

20.1 Hearer-oriented bias

RT 主要关注：

addressee 如何理解 stimulus

但相对较少讨论：

  • communicator 如何选择表达方式；
  • speaker production；
  • 多个参与者如何协作建构意义；
  • meaning 如何在互动中协商。

20.2 对单个 utterance 的关注较强

RT 的经典分析通常集中于：

  • 单个 utterance；
  • utterance pair。

但现实互动中的意义可能：

  • 随着多轮 discourse 改变；
  • 被后续 response 确认；
  • 被修正；
  • 被重新解释。

因此：

如何解释 extended interaction 中意义的动态发展是可以继续推进的问题。

20.3 Speaker-unintended inference

经典 ostensive-inferential framework 主要解释：

speaker intentionally communicates → hearer recognises intention。

但现实中还有大量：

speaker-unintended information / inference。

例如口音、声线、无意表情等。

它们显然影响理解，却不一定构成严格意义上的 speaker meaning。

20.4 Relevance 的实验测量

课件进一步提出一个方法论问题：

如何实际测量 processing effort 和 cognitive effects？

可能的实验指标包括：

  • processing time；
  • attention；
  • multitasking interference；
  • ERP；
  • fMRI 等。

因此，relevance 虽然具有明确理论方向，但它的心理现实性和操作化仍需要实验研究支持。

21. 总结

关联理论可以浓缩为下面这条链：

[ ]

展开来说：

  1. 交际者制造 ostensive stimulus；
  2. 听者因此期待该刺激具有 optimal relevance；
  3. 听者按照 accessibility 顺序处理解释；
  4. 沿着 path of least effort 搜索 cognitive effects；
  5. context 并非固定，而是在过程中动态选择；
  6. linguistic decoding 与 inference 共同构建 explicature；
  7. 进一步 inference 形成 implicature；
  8. lexical concepts 可以通过 concept adjustment 发生 narrowing / broadening；
  9. procedural expressions 可以指导推断；
  10. 一旦解释产生足够 cognitive effects 来证明 processing effort，听者就停止搜索；
  11. 有些 utterances 会产生大量 weak implicatures / poetic effects；
  12. 从说话者行为得到的信息若并非有意传达，则不应自动视为 implicature。

关联理论认为，人类认知倾向于最大化相关性，而每个明示交际行为都会引发关于最优相关性的期待；听者因此按照解释的可及性，以最小处理努力寻找足够的认知效果，并在这一过程中动态选择语境、构建外显义和含义，直到相关性期待得到满足。
