2026.08.12 巴瓦鲁魔法图书馆

授课教师：Marina Terkourafi

授课地点：Leiden Linguistic Summer School，Leiden

日期：2026 年 7 月 9 ~ 10 日

1. 关联理论（Relevance Theory）的基本定位

Relevance Theory (RT) 由 Sperber 与 Wilson 提出，是关于 cognition and communication 的理论，而不只是关于语言结构的理论。它继承 Grice 对 intentional communication 与 inference 的重视，但不再以一组 conversational maxims 为中心，而是从人类认知系统如何分配有限注意力出发解释交流。

RT 同时适用于 verbal、nonverbal 和 multimodal stimuli。理解一个 utterance 时，得到一个 truth-evaluable proposition 只是整个 comprehension process 的一步，而不是交流本身的最终目的。

2. 关联性（Relevance）：认知效果（Cognitive Effects）与处理努力（Processing Effort）

一个 stimulus / interpretation 的 relevance 取决于 cognitive effects 与 processing effort 的平衡：

  • 在 effort 相同的情况下，产生更多 cognitive effects → 更 relevant；
  • 在 effects 相同的情况下，需要更少 processing effort → 更 relevant。

典型 cognitive effects 包括：

  • strengthening existing assumptions；
  • eliminating false assumptions；
  • deriving new assumptions / conclusions。

Relevance 是 relative to an individual 的：不同人的 background knowledge、goals 和 cognitive environment 不同，因此同一 stimulus 对不同人可以具有不同程度的 relevance。

RT 有两个原则：

  • 关联性的认知原则（Cognitive Principle of Relevance）：人类认知系统总体倾向于 maximisation of relevance。
  • 关联性的交际原则（Communicative Principle of Relevance）：每个 ostensive act 都带有对其自身 最佳关联（optimal relevance） 的预期。

这里要区分 maximal relevance 和 最佳关联（optimal relevance）。认知系统总体追求 maximal relevance，但 communicator 并不保证自己的 stimulus 是绝对最相关的，只让 hearer 合理期待：它值得处理，并且已经相关到足以 justify 当前 processing effort。

这与 Grice 的 MeaningNN 有明显连续性：speaker 希望自己的 intention 被 hearer 识别，hearer 则因为把某个 behaviour 当成 ostensive stimulus，开始寻找 speaker intended interpretation。

RT 的理解启发式是：

按 accessibility 顺序考虑候选解释，沿 least-effort path 获得 cognitive effects；当期待的 relevance 得到满足时停止。

因此 hearer 不会穷举全部可能解释。最先 accessible 的 disambiguation、referent、enrichment 和 contextual assumptions 会优先被考虑，只要某个 interpretation 足以满足 relevance expectations，理解过程就可以停止。

4. 语境是变量（Context Is a Variable）

RT 与很多传统模型的一个关键差别是：context 不是先完整固定、然后再拿来计算意义的背景集合。

在理解过程中，hearer 会动态调用和选择最 accessible、最有可能产生足够 cognitive effects 的 assumptions。于是：

  • disambiguation；
  • reference assignment；
  • enrichment；
  • contextual assumptions；
  • explicatures；
  • implicatures；

可以在线、局部、相互制约地发展，而不必理解为严格的线性顺序。

这也是 RT 处理“为什么不同人会从同一句话得到不同 interpretation”的重要方式：不同人的 cognitive environment 与 assumption accessibility 不同。

5. 明说内容（Explicature）与含义（Implicature）

RT 对 explicit / implicit content 的划分与 Grice 不完全相同。

  • 明说内容（explicature）：由 linguistic decoding + inference 得到，是 utterance logical form 的发展。
  • 基本层明说内容（basic-level explicature, BLE）：speaker 直接传达的 truth-evaluable proposition。
  • 高阶明说内容（higher-level explicature, HLE）：把 BLE 嵌入 speech-act、attitude 或 evaluation description 中。
  • 含义（implicature）：完全通过 inference 得到的独立 proposition，具有自己的 truth conditions。

例如：

Fortunately, Mary is coming.

可以分析为：

层级 内容
Basic-level explicature Mary is coming
Higher-level explicature It is fortunate that Mary is coming
Implicature（在特定前文下） Mary can help with the problem

因此 RT 特别强调：explicit content 本身也可以包含大量 pragmatic inference。Pragmatics 不是只负责在“字面 proposition”后面再加 implicature。

6. 概念调整（Concept Adjustment）与词汇语用学（Lexical Pragmatics）

RT 认为 lexical meaning 往往具有一定程度的 underspecification，实际 utterance interpretation 中会发生 relevance-driven 概念调整（concept adjustment）。常见方向包括：

  • narrowing：临时概念比词典概念更窄；
  • broadening：临时概念比严格词典意义覆盖更广。

例如 Boys will be boys 在不同 contexts 中可能得到不同的 ad hoc concept，而不是先机械地产生一个无信息的 tautology，再额外附加含意。

这使 RT 能把某些 pragmatic intrusion into lexical meaning 直接放进 explicature construction 中，而不是全部处理为 proposition 之外的 implicature。

7. 概念意义（Conceptual Meaning）与程序意义（Procedural Meaning）

RT 还区分：

  • 概念意义（conceptual meaning）：提供 representational content，也就是“表示什么”；
  • 程序意义（procedural meaning）：主要指导 hearer 怎样进行 inference。

例如：

Calum is vegan but he loves spicy food.

8. RT 与 Grice / Neo-Gricean 的主要差别

问题 Grice / Neo-Gricean Relevance Theory
核心机制 CP、maxims / heuristics relevance-guided comprehension
Context 用于推导 utterance meaning 在理解过程中动态选择
Explicit content 较接近 what is said explicature 可包含丰富 pragmatic enrichment
Conventional implicature 保留独立类别 常以 procedural meaning 处理
GCI / PCI 常作理论区分 不认为必须由两套基本机制解释
Lexical meaning 多作为推理输入 可发生 relevance-driven concept adjustment
Irony 可由 maxim exploitation 等解释 echo / attribution + dissociative attitude

核心框架：

RT 的核心不是“寻找最聪明的解释”，而是解释为什么 hearer 会优先选择某些 context 和 interpretation，并在获得足够 relevance 后停止处理。
