Leiden Linguistic Summer School 2025 语音学和音系学 Day 9

授课教师：Ahmed Sosal

授课地点：Leiden Linguistic Summer School，Leiden

日期：2025 年 7 月 31 日

一、音系规则：从观察到形式化

1.1 音系规则描述什么

音系规则（phonological rules）描述某种语言中在特定环境下系统发生的声音变化。它们不是逐词背诵的发音清单，而是对说话者能够无意识遵循的概括。

规则可以用来说明：

  • 同一音位为何在不同环境中有可预测的语音实现；
  • 同一词素在不同形式中为何出现规律性交替；
  • 哪些声音关系是系统性的，哪些只是偶然的词汇差异；
  • 语音实现如何受到音段、音节、词界和形态边界的共同制约。

分析时必须先分开观察到的表层形式与提出的抽象分析。规则是对数据的假设，应能够覆盖相关例子、指出适用环境，并经得起反例检验。

1.2 Totontepec Mixe：鼻音后塞音浊化

讲义以 Totontepec Mixe 的第二人称领属形式说明规则推导。领属前缀为 m-，加到词干后，词干首的清塞音发生浊化：

基本形式 意义 带第二人称领属形式 意义
tohk 房屋 mdəhk 你的房屋
pahk 骨头 mbahk 你的骨头
kak 胸部 mgak 你的胸部

从数据到规则可分成三个步骤：

  1. 确定自然类：/t p k/ 都是清塞音；
  2. 确定变化：它们分别实现为 [d b g]，发音部位和发音方式保持不变，声带振动状态改变；
  3. 确定环境：变化发生在领属前缀 m- 的鼻音之后，并跨越词素边界。

可以用散文表述为：“清塞音在鼻音后浊化。”用特征表达时，目标类可写为清的非持续阻碍音：

该规则只改变 [voice] 的值，因此 /t p k/ 分别保留其原有的发音部位和塞音性质而变为 [d b g]。若要把这条规则作为完整分析，仍须检查所有相关清塞音、所有鼻音环境及可能的反例，不能仅根据三组词就假定它在无条件下适用。

1.3 规则记法与转写层次

讲义采用的基本规则格式为：

它表示：目标 A 在左环境 C 与右环境 D 之间实现为 B。下划线 __ 标出目标所在的位置，斜线 / 读作“在……环境中”。

符号或记法 含义 例子
[ ] 语音转写，写实际发出的声音 [tohk]
/ / 音位或底层形式 /tohk/
< > 正字法或拼写形式 <house>
# 词界 A -> B / # __ 表示在词首
∅ 零，即没有音段 A -> ∅ 表示删除
+ 词素边界 A -> B / __ + C
( ) 可选成分 A -> B / C (D) __

规则格式要求明确区分四件事：什么发生变化、变成什么、在哪里变化，以及该变化是否与词界或形态边界有关。

1.4 好规则的四项条件

条件 分析要求
自然类 规则应优先作用于由共享特征定义的音段组，而不是任意符号列表
环境 说明触发或阻断条件，包括邻近音、词界、音节位置和词素边界
方向性 明确输入到输出的方向，而非只说两个形式“相关”
系统性 规则概括多个形式的共同模式，而非为单个例外临时设定

特征表示的价值在于它能够说明为何某些音段一起发生变化。例如，“所有清塞音在鼻音后浊化”比“p、t、k 分别变成另一组音”更能体现数据中的自然类概括。

二、常见音变 I：中和与同化

2.1 中和

中和（neutralization）指原本存在的音位对立在特定环境中失去表层区别。重要的是：对立仍可在其他环境中成立，只是在受限位置两个或多个底层类别汇合为同一（或无法区分的）表层结果。

讲义把英语 /s/ 后清塞音不送气也列在“neutralization”页上，但这里需要修正术语：英语通常并不存在独立的 /pʰ/ : /p/ 送气音位对立，因此 [pʰ] ~ [p] 更合适分析为同一音位的条件性送气变体，而不是真正的音位中和。

分析中和时，要写清：

  1. 原本哪两个或哪几类音位有对立；
  2. 对立在哪个环境中不再有表层差别；
  3. 是否有形态交替、近似最小对立或其他证据支持底层对立；
  4. 中和是否由更一般的音位配列或发音限制驱动。

2.2 同化：发音部位

同化（assimilation）是一个音段受另一个音段影响，获得与其相同或更相似的特征。英语短语中的鼻音常展示发音部位同化：

表述方式 规则
描述性表述 齿龈鼻音在双唇辅音前变为双唇鼻音
音位规则 /n/ -> [m] / __ [+labial]
特征规则 [+nasal, +alveolar] -> [+nasal, +labial] / __ [+labial]

规则的重点是鼻音只改变发音部位，不改变 [+nasal]，这使它成为“特征同化”而非整个音段被替换的分析。

2.3 清化与擦音化：不要都归入“同化”

讲义在 assimilation 部分并列了两个现象，但它们的分析性质不同：

现象 讲义例子 更准确的分析
流音清化 英语清塞音后的词首流音 清塞音后的 /l r/ 常出现明显的部分清化/清化；这是受相邻清音影响的同化性、共构过程，并且在英语中是音位变体过程
擦音化 巴布亚新几内亚某南岛语 词末 /t/ 在元音起始后缀前变为 [s]：/t/ -> [s] / V __ + V；这更适合称为 spirantization/fricativization（擦音化），属于 lenition（弱化）

第二个过程并没有因为邻音本身带有“擦音”特征而变得更像邻音，因此按同化的定义，它不应仅因为讲义页标题写了 “assimilation in manner” 就当作典型同化。例子如 ganat + 后缀 → ganas-e，jamot + 后缀 → jamos-ivin；关键环境是跨词素边界的元音之间。

三、常见音变 II：异化、删除、插入、换位与和谐

3.1 异化

异化（dissimilation）使原本相似的音段在某些性质上变得不那么相似。它比同化少见，但同样必须说明触发音、目标音、作用范围和变化特征。讲义指出，异化可被理解为避免两个相似成分过度相近、从而有助于保持可辨识性的过程；这是一种可能的功能解释，不能替代具体语言的数据分析。

Kikuyu 语的无定式前缀给出一个例子。讲义将两个形式分别列为：

词根首辅音 前缀形式 讲义中的概括
浊辅音，如 /n r ɣ ŋ/ ko- 前缀保持清塞音 [k]
清辅音，如 /k c ʃ t/ ɣo- 前缀的 [k] 变为浊持续音 [ɣ]

3.2 删除

删除（deletion；elision 是常见的一类删除现象）是一个音段在特定环境中不在表层形式中实现。讲义以法语定冠词与元音起始名词的组合说明：冠词末尾元音可在元音前删除。这里更稳妥的概括是避免特定形态组合中的元音相邻（hiatus）并满足法语的形态音系模式；不能据此推断“法语一般不允许 V-起始音节”，因为法语本身当然存在元音起始音节。

  • 被删的是哪个词素中的哪个元音；
  • 删除是否只发生在特定冠词或词类；
  • 词界与词素边界是否同样允许规则适用；
  • 是否存在保留元音、插入滑音或其他避免元音连缀的策略。

3.3 插音

插音（epenthesis）是原先没有的音段在特定环境中出现，常用于避免语言不允许的音段序列或维持可接受的音节结构。

讲义用荷兰语指小后缀说明：后缀具有底层形式 -tje。当名词以鼻音、流音、滑音等响音结尾，或以复杂辅音群结尾时，后缀前可出现 [ə]；而单个阻碍音结尾时通常不出现这一元音。

名词末尾类型 讲义中的表层模式
单个阻碍音 如 pak-je、kat-je，不出现 [ə]
响音或复杂辅音群 如 dal-ə-tje、man-ə-tje、ster-ə-tje，出现 [ə]

3.4 换位

换位（metathesis）指音段、音节或其他单位的线性顺序发生重排。讲义列举：

例子 变化
古英语 brid 演变为 bird
言语失误或变体型形式 ask 与 aks 的顺序交替
《圣经希伯来语》 /t/ 与咝音的顺序重排，使咝音成为前一音节的尾音，而 /t/ 成为后一音节的起始

换位不能只写成“两个音交换了位置”。分析应说明哪两个单位参与、重排是否跨音节、是否受音节结构驱动，以及是否存在形态或词汇限制。

3.5 和谐规则

和谐（harmony）指一个音系单位受到同一词或短语中另一个单位影响而在某个特征上趋同。它与局部同化相似，但影响距离可以更远，且往往有明确的作用域。

讲义列出几类常见和谐：

  • 元音和谐：如 [±back]、圆唇度、高度或 ATR 特征在一个词内协调；
  • 咝音和谐：咝音在特定形态域内共享相关特征；
  • 其他跨音段或跨音节的特征一致性。

土耳其语和匈牙利语常被用于展示元音和谐：一个词中的元音可共同呈现前/后或圆唇等特征。分析和谐时应明确触发音、目标音、和谐域、阻断因素，以及特征是否从左向右、从右向左或双向扩展。

四、形态学与形态音系

4.1 形态学的基本单位

形态学（morphology）研究词的内部结构与构词方式，包括屈折形态和派生形态。其基本单位是词素（morpheme），即最小的有意义单位。

单位 定义 讲义例子
词根（root） 承载核心词汇意义的成分 -self-
词干（stem） 可再接受屈折或派生成分的形式 self-ish
词缀（affix） 附加于词根或词干的成分 前缀 un-、后缀 -ish、中缀
词素变体（allomorph） 同一词素的不同形式 英语复数 /-s/、/-z/、/-ɪz/

词素变体的差异可以由音系环境、形态范畴或词汇条件触发。区分这些条件，是形态音系分析的出发点。

4.2 什么是形态音系

形态音系（morphophonology）研究形态过程与音系过程的互动，特别关注：

  • 音系条件如何改变词素的表层形式；
  • 形态范畴、词缀或词素边界如何限制音系规则；
  • 同一个词素为何在不同形态环境中呈现不同音段；
  • 同一音系过程为何只在派生、屈折、复合或特定词汇类中适用。

因此，形态音系过程并不是一种独立于同化、删除或插音之外的新“音变类别”。相反，这些常见过程一旦受到词素、词缀或构词结构的制约，就成为形态音系分析的对象。

4.3 英语前缀交替与形态边界

讲义以英语前缀 in- 的交替说明规则的形态敏感性：

在这些拉丁来源的派生形式中，前缀末尾 /n/ 在 /l/ 或 /r/ 前发生完全同化，表面得到 il-、ir-。这不是英语中任何 /n + l/r/ 序列都会发生的一般语音规则，而是对特定前缀及其形态域敏感的交替。讲义同时提醒：相似的音段序列并不自动触发同一规则，例如 unloved 中的 un- 不表现为相同交替，复合词 sunlight 也不应仅凭相邻音段就假定有前缀同化。

这说明规则的环境不能只写作“某音前”，还要问：

  1. 目标是否位于特定词缀中；
  2. 词素边界的类型是什么；
  3. 该过程作用于派生、屈折、复合还是词内；
  4. 是否只有某个词缀作为触发者或目标。

讲义还提到一个语言特定的咝音和谐模式：后缀可以对词根施加和谐，而词根不反向对前缀施加同样的过程。讲义该页没有给出足够语言背景，因此这里应把它当作“形态域可以限制和谐方向”的示意，而不是咝音和谐的一般定义。

4.4 形态音系规则的分析步骤

在此过程中，应避免两个极端：不能把所有交替都当作任意背诵的同位形式，也不能在缺少证据时把所有差异都强行还原成一个纯音系规则。
