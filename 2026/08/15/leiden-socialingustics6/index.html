Leiden Linguistic Summer School 2025 社会语言学 Day 6

2026.08.15 巴瓦鲁魔法图书馆

授课教师：Marina Terkourafi

授课地点：Leiden Linguistic Summer School，Leiden

日期：2025 年 7 月 28 日

一、语言纯粹主义与混合实践

1.1 语言纯粹主义

语言纯粹主义（linguistic purism）认为：

“语言”应只以其“纯粹形式”使用；把不同“语言”的片段混合起来，会产生缺陷、腐化或扭曲的文本和话语。

本讲反对把这种观念当作语言事实。历史上不存在真正“纯粹”的语言：

  • 不同地点的人群始终会相遇、交流；
  • 他们的说话方式会相互影响；
  • 影响不仅包括借词，也可能包括语音和语法结构；
  • 人们实际互动中产生的常是混合性的说话与书写方式。

语言标准化试图清除被视为“外来”的元素，并用听起来更“本土”的形式替换它们，从而使语言看起来更纯粹。讲义用“纯水 H2O”作比喻：纯水并非日常自然状态，而是实验室中人工制造的状态；所谓“纯语言”也具有类似的人工性。

1.2 代码混合与代码转换

讲义首先作一个形式上的区分：

现象 英文 基本定义
代码混合 code mixing 在同一句内部组合来自不同“语言”的形态素、词、短语或从句，即句内混合（intra-sentential）
代码转换 code switching 在句与句之间组合不同“语言”，即句际转换（inter-sentential）

这个区分有助于描述形式，但术语使用并不完全统一：教材特别提醒，许多研究者会把 code mixing 当作较宽泛的总称，同时涵盖句内混合与句际转换。因此，阅读文献时应先确认作者如何定义 code mixing 与 code switching，而不要把两者的边界当作普遍固定的术语事实。

更重要的是，这种形式区分不应让人误以为日常实践总能清楚地被切分为若干完整、封闭的“语言”。后半讲的 translanguaging 理论正是对这种边界清晰观的挑战。

二、为什么人们转换代码

2.1 情境性代码转换

情境性代码转换（situational code-switching）由情境、话题或参与者的变化触发。

其特点是：

  • 不同语言/代码被常规地分配给不同情境；
  • 说话者遵循“何时、何地、对谁、怎样说”的交际规范；
  • 在给定话题、参与者和场合的条件下，所用代码往往是可预测的；
  • 这种转换通常是无标记的（unmarked）：不是说话者为特殊效果作出的突出选择，而是情境本身使该选择成为预期。

例如，在某个家庭中与祖父母使用一种语言、在学校使用另一种语言，可能属于情境性转换。

2.2 隐喻性代码转换

隐喻性代码转换（metaphorical code-switching）指说话者有意使用不完全符合当前情境预期的代码，以实现特殊效果，例如：

  • 批评；
  • 取笑；
  • 表达亲近；
  • 显得受教育程度高；
  • 表达愤怒；
  • 改变互动的正式度、距离或权力关系。

这种转换是有标记的（marked）：说话者在当下具有不同代码可选，且选择不是单由话题、情境或参与者决定。

有标记并不表示意义固定。某次转换究竟表示亲密、讽刺、炫耀、反讽还是愤怒，仍取决于具体情境、参与者关系和已有的索引意义。

2.3 话语相关代码转换

会话分析（Conversation Analysis）强调话语相关代码转换（discourse-related code-switching）。这类转换由当下会话需求触发，例如：

  • 修复误解；
  • 获得注意；
  • 标记话轮边界；
  • 确保对方理解；
  • 推进会话顺利进行。

至少有一部分话语相关转换，并不携带超出会话组织之外的强烈社会意义。换言之，不能把每次代码转换都自动解释为身份表演或特殊立场；有时它首先是互动协调的工具。

2.4 三种取向的关系

类型 主要触发因素 是否由说话者主动选择 典型社会意义
情境性转换 情境、话题、参与者改变 选择空间较小 遵守交际规范，通常无标记
隐喻性转换 追求特殊互动效果 较强 亲近、距离、批评、幽默、权威等
话语相关转换 会话即时组织需要 视具体互动而定 可能主要服务于修复、注意和顺畅互动

这三类并非永远严格互斥；同一次转换可能同时受情境规范、个人策略和会话组织影响。

三、代码的互动意义

3.1 多语能力与代码的社会联想

情境性、隐喻性和话语相关代码转换通常要求使用者对所转换的代码具有相当程度的能力；在隐喻性转换中，受众也常需要具备相应知识才能理解其效果。

多语者往往把自己掌握的不同代码和变体，与其对不同社会群体的情感和经验联系起来。

讲义使用两个概念概括这种关联：

概念 含义
我们代码（we-code） 用于表达对某群体的归属、团结、亲密，常见于群体内部互动
他们代码（they-code） 常与正式场合、外群体互动或制度性关系相关

多语使用者可策略性地调用不同代码，制造亲近感或与他人拉开距离。

但“我们代码 = 亲密”“他们代码 = 距离”只是分析起点，而不是普遍固定规则。代码转换的在地意义远比这一二分复杂：同一种被称为“我们代码”的资源，也可能在特定场合表达批评、讽刺、权威或排除。

四、跨越（crossing）与双重发声

4.1 什么是 crossing

跨越（crossing）指人们混合自己只有限度掌握的代码，实际上是从“他人的语言”中挪用词语或短语，并将其插入自己的表达。

crossing 的社会意义依赖：

  • 使用者与被挪用代码相关群体之间的关系；
  • 使用者实际掌握该代码的程度；
  • 互动情境；
  • 交际目的；
  • 受众如何理解这一挪用。

因此，crossing 不能仅通过“是否使用了外来词”来判断其政治或伦理意义；同一形式可被体验为亲近、玩笑、尊重、刻板印象、嘲讽或冒犯。

4.2 双重发声（double-voicing）

crossing 常与双重发声（double-voicing）相关：使用者复制或模拟他人的说话方式，同时对这种方式作出评论。

双重发声可以：

方向 可能效果
正向 表达认同；与某群体结盟；借用其地位或声望，例如白人嘻哈表演者采用非裔美国人语言资源
负向 模仿、嘲讽、批评或贬低他人

“复制别人说话”本身不自动等于尊重或歧视；分析必须把资源放回权力关系、历史、受众和具体互动目的之中。

五、从 code switching 到 translanguaging

5.1 超多样性（superdiversity）

讲义提到 translanguaging、polylingual languaging、code meshing、metrolingualism 等术语。它们共同指向一个观察：在越来越超多样化（superdiverse）的社会中，个人的 repertoire 越来越复杂。

超多样性不只意味着移民群体与多数群体之间的差异增加，也意味着同一移民或少数群体内部的差异增加，即“多样性的再多样化”（diversification of diversity）。

来自同一国家的人可能：

  • 因不同原因迁移；
  • 拥有不同法律身份；
  • 具有不同教育和职业经历；
  • 追求不同兴趣和生活目标；
  • 接触不同资源与网络。

因此，不能只因人们共享一种被命名的“语言”、宗教或族群身份，就把他们当成单一、同质的群体。

5.2 Translanguaging 的定义

García 与 Li Wei（2014）将 translanguaging 定义为：

许多人在交际时从事的流动、动态实践；这种实践跨越被命名语言、语言变体以及语言与其他符号系统之间的边界。

这里的 -ing 很重要：它强调人们在实际使用中主动创造语言，而不是把既有语言系统原封不动地搬到情境中。

通过 translanguaging，使用者会创造新的混合形式和构式；这些形式可能无法明确归属为某一种或另一种“语言”。

5.3 与代码混合/转换的差异

视角 基本单位 重点
代码混合/代码转换 可以区分的“语言”或“代码” 描述使用者在代码之间的混合、切换及其互动功能
Translanguaging 使用者的整体 repertoire 强调资源流动、动态组合，以及跨越既有语言边界的意义实践

两种视角都可用于研究多语实践，但理论重心不同：前者通常以相对可区分的代码为起点，后者更强烈地质疑把实践预先切分为边界清晰的语言实体。

六、translanguaging 的教育与权力意义

6.1 对主导语言意识形态的挑战

translanguaging 挑战并改变主导性的语言意识形态，尤其是教育与其他制度领域中的纯粹语言观。

当习惯在家庭和日常生活中使用混合资源的学生，被要求在学校只使用某种“纯粹”代码时，他们实际上被要求转换到一个并非自己日常实践的代码。

这类转换的目标不是生成混合意义，而是人为地生成“纯语言”形式。其后果可能是：

  • 学生不能使用自己最自然、最熟悉的交际方式；
  • 学校将其日常混合实践视为异常或低等；
  • 学生在学习中处于不利位置；
  • 标准语意识形态与单语意识形态进一步得到强化。

6.2 课堂中的 translanguaging

在课堂中允许 translanguaging，意味着鼓励学生调动 repertoire 的全部资源进行沟通和学习。

它可以：

  • 使学生的日常交际实践被视为正常、有效；
  • 帮助学生跨越不同语言能力与学科资源；
  • 增加混合资源在学校中的可见性；
  • 赋权使用 translanguaging 的学生；
  • 长期推动人们把 translanguaging 视为所有语言使用者的自然状态，而非偏离“纯语言”的缺陷。

这并不意味着学校不再教授标准书写、体裁规范或特定学科语言，而是意味着这些资源不应以否定学生既有 repertoire 为代价。

七、与前几讲概念的联系

本讲将前几讲的概念串联起来：

代码转换可体现交际能力和索引意义；crossing 体现资源挪用与双重发声；translanguaging 则把焦点放在使用者的动态 repertoire 与跨边界实践上。三者都要求研究者避免把“语言边界”当作无需解释的自然事实。
