C 与 CP

补语标记

引入嵌入从句的成分叫作从属连词/补语标记（subordinating conjunction / complementiser），其范畴为 C：

常见的英语补语标记包括 that、if、whether、for。它们有两个重要性质：

  1. 它们位于嵌入句中 Spec,TP 的主语之前，因此位于 TP 之上的结构位置；
  2. 它们属于嵌入句，而不是矩阵句。

第二点可以从话题化看出：

完整的 that 从句可以作为一个整体移动；单独把 that 留在矩阵句末尾则不成立。这说明 complementiser 属于嵌入句内部并处在 TP 之上。更准确地说，C 是嵌入有限句的最高中心语（head），CP 才是该从句的最高投射（projection）。

嵌入、并列与递归

CP 在更大结构中的功能

CP 可以像其他成分一样出现在不同的句法位置：

CP 类型 例句 与矩阵句的关系
对象从句 I know [that John eats apples]. know [V, uC] 选择 CP 对象
主语从句 [That John eats apples] surprises Jack. CP 位于主语位置；v 可选择 CP 论元
附加从句 Amy smiles [because it is raining]. because 从句附加到矩阵结构，不是 smile 选择的论元

对象从句显示词汇动词可带 [uC] 特征；主语从句显示 CP 也可作为名词性主语位置的内容；附加从句则把 Day 8 的 Adjoin 分析扩展到句子层级。

从属与并列不同

that、if、because 等从属连词使一个 CP 嵌入另一个结构。与此不同，and、but、or 是并列连词（coordinating conjunctions）：它们把两个同层级短语放在一起，而不让其中一个嵌入另一个。

三例分别是 NP、AP 和 CP 的并列。讲义在这里要建立的关键点是：被协调的成分处在同一结构层级，彼此不形成“一个嵌入另一个”的从属关系。本讲并没有进一步规定 conjunction phrase 内部必须采用哪一种具体分枝结构，因此不必额外把“两个并列项彼此直接为姐妹节点”当作已经证明的结论。相比之下，从属 CP 可作为较高谓词或短语的补足语、指定语或附加语。

句型特征与一般疑问句

Clause type

that 与 if/whether 的关键差异不仅是词汇意义，而是它们引入的句型（clause type）。句型是 C 上的形态句法特征：

句型 特征 例子
陈述句（declarative） [clause-type: Decl] Kate will go to the cinema.
疑问句（interrogative） [clause-type: Int] Will Kate go to the cinema?
命令句（imperative） [clause-type: Imp] Go to the cinema!

两种疑问句的 CP 都具有 [clause-type: Int]；差异在于 wh 疑问句还涉及一个带 [wh] 特征的被询问成分和 C 上的 [uwh] 特征。

矩阵一般疑问句：T-to-C 移动

一般疑问句中，有限助动词或情态动词位于主语之前：

这不是主语与动词的简单交换，而是 T-to-C movement：带 [clause-type: Int] 的矩阵 C 使 T 移到 C。

T-to-C 是中心语移动，和之前的 V-to-v、V+v-to-T 同类。低位 ⟨T⟩ 副本不发音；高位 C+T 的 will 在表面上位于主语之前。

为什么嵌入一般疑问句不倒装

嵌入一般疑问句已经有显性的疑问补语标记 if 或 whether 占据 C：

whether 已经填充 C，因此 T 不能再移至 C。嵌入从句维持主语--T 顺序。

这个对比说明：T-to-C 移动并不是“疑问句一律倒装”，而是只有当矩阵疑问句的 C 未被显性补语标记占据时，T 才能移到 C。

Wh 疑问句与 wh 移动

wh 疑问句的两种移位

比较陈述句和 wh 疑问句：

疑问句中发生了两种不同的移动：

  1. 有限情态 should 位于主语前：T-to-C 中心语移动；
  2. 被询问的对象 what 位于情态词前：wh 短语移至 Spec,CP。

wh 词包括 what、where、when、who、how、which 等，带有 [wh] 特征。wh 疑问句的 C 则带有未赋值/未检查的 wh 特征：

C 先与 TP Merge，以检查 [uT]；[uwh] 则投射到 C'，使 wh 成分被吸引到 Spec,CP。移动后，wh 成分与 C' 处于姐妹关系，[uwh] 得到检查并删除。

wh 移动是短语移动，不是中心语移动；被移动的对象可以是 NP、PP、AdvP 等完整成分，例如 what、where、when。

嵌入 wh 疑问句

wh 移动不仅发生在矩阵句，也发生在嵌入疑问句：

在嵌入 wh 疑问句中：

  • wh 成分仍移到 Spec,CP；
  • T 不移到 C，因此不发生主语--助动词倒装；
  • 嵌入 C 已经是疑问 C，即使它在英语里通常不发音。

这可以解释为什么英语嵌入 wh 疑问句是 what John should buy，而不是矩阵句式的 what should John buy。

方言证据：wh 词与 C 可以同时显现

如果 wh 短语本身占据 C 头位置，那么同一个 C 位置就不应还能同时出现独立的显性补语标记。荷兰语和德语的一些方言却显示，wh 短语之后仍可出现显性 C：

三类移动与疑问句总结

三类移动

至此课程已经出现三种移动：

类型 移动单位 目标
中心语移动（head movement） 中心语 X 更高中心语位置
A-移动（A-movement） 论元短语 XP 论元位置
A′-移动（A-bar / A′ movement） 短语 XP A′-位置

Spec,TP 是 A-position，因此主语 EPP movement 属于 A-movement；Spec,CP 是 A′-position，因此 wh movement 属于 A′-movement。这里的分类取决于移动的目标位置，而不是移动成分本身是否原来是论元：例如宾语 what 原本就是 buy 的论元，但移到 Spec,CP 后所发生的仍然是 A′-movement。

矩阵与嵌入疑问句

句型 wh 移动 T-to-C 移动 例子
矩阵一般疑问句 无 有 Will you buy apples?
嵌入一般疑问句 无 无 I wonder whether you will buy apples.
矩阵 wh 疑问句 有 有 What should John buy?
嵌入 wh 疑问句 有 无 I asked what John should buy.
