Leiden Linguistic Summer School 2025 历史语言学 Day 5

2026.08.13 巴瓦鲁魔法图书馆

授课教师：Niels Schoubben 授课地点：Leiden Linguistic Summer School，Leiden 日期：2025 年 7 月 25 日

1. 重分析与类比

重分析（reanalysis）指形式表面不一定立即变化，但说话者对内部结构的分析改变。经典例：

[Hamburg]-[er] → [ham]-[burger]

原来的 -er 与 Hamburg 的地名结构被重新切分为 burger，随后才能产生 cheeseburger, veggie burger。类似地，bikini 被重新分析后产生 monokini 等新构词。

类比（analogy）则是根据已有模式创造或改变形式。典型的四项类比（proportional / four-part analogy）：

teach : taught :: catch : X
X = caught

类比必须有一个模型，常常在原有区别因音变而模糊时增强形态透明度。

2. 类比整平、扩展与 Sturtevant 悖论

类比整平（analogical leveling）

音变使同一形态素产生多个异形体（allomorphs），类比把差异减少。

拉丁语：

  • 早期：nom.sg. honos : gen.sg. honōs-is
  • r 音化后：honos : honōr-is
  • 类比：nom.sg. honor

类比扩展（analogical extension）

某个交替原本只在音系条件允许的形式中出现，后来被扩展到并不满足原始音变条件的词。例如西班牙语某些词的双元音交替被类推到新的词形。

Sturtevant 悖论（Sturtevant’s paradox）

  • 规则音变在音系上规则，却常制造形态不规则；
  • 类比变化在音系上不规则，却常制造形态规则。

这是理解历史形态学的核心：今天的“不规则词形”常是过去规则音变的遗迹；今天的规则范式也可能是后来类比重建的结果。

3. 其他形态变化

过度修正（hypercorrection）

说话者为了避免被认为“不规范”的形式，错误地把一个本来无需修改的形式“修正”掉。它通常预设说话者意识到至少两种具有不同社会评价的变体。

污染（contamination）

语义相关的词互相影响，使形式变得更相似：

  • English male vs. femelle → male vs. female；
  • 数词、星期名称等系列中特别常见。

民间词源（folk etymology）

不透明的词被重新塑造成包含熟悉词素的形式：

  • Spanish cucaracha → English cockroach；
  • Old English brȳdguma → bridegroom（受 groom 影响）。

民间词源的关键不是“真正发现词源”，而是提高当代说话者眼中的形态透明度。

4. 句法变化：重分析 + 扩展

讲义把句法变化概括为两个连续过程：

  1. 对已有歧义结构重分析；
  2. 把新分析扩展到原来不允许的环境。

英语 let’s 的历史说明，一旦 let’s 被重新理解为第一人称复数祈使标记，后面的动词也可以按“祈使动词”重新分析，之后产生新的否定组合。

现代希伯来语 yeš li sefer “I have a book”（字面“there is a book to me”）的分析变化则说明：同一表面结构可从 VERB–POSSESSOR–SUBJECT 被重新理解为更接近 VERB–SUBJECT–OBJECT 的结构，随后宾语标记也可以类推扩展。

5. 语法化（Grammaticalisation）

语法化指词汇项目或结构在某些语境中获得语法功能。经典路径可概括为：

实词（content word） > 功能词（function word） > 附着词（clitic） > 屈折词缀（inflectional affix） > Ø

讲义以英语 going to 为核心：

  1. I am going to Leiden to ...：仍表示真实移动；
  2. I am going to get married tomorrow：可同时理解为“移动”或“未来计划”；
  3. 结构被重分析为未来标记；
  4. 扩展到根本不可能表示移动的主语：It is going to rain；
  5. 音系弱化：going to → gonna → -a / imma 等口语形式。

语法化常伴随：

  • 音系弱化（phonological reduction）；
  • 语义漂白（semantic bleaching）：具体词义减少、语法意义增强；
  • 句法黏着度提高：独立实词 → 助动词/功能词 → 词缀。

6. 形态化（Morphologisation）与语法更新

形态化（morphologisation）是语法化的一种结果：独立词变成黏着形态素。罗曼语副词后缀 -mente：

Latin mente “with a mind” → [ADJ + mente]短语 → 方式意义 → univerbation → 副词后缀

即 Givón 的概括：“today’s morphology is yesterday’s syntax.”

常见语法化来源包括：

  • 后置词 → 格词尾；
  • “站、躺”等实义动词 → 系词/助动词；
  • 指示代词 → 定冠词；
  • 数词“一” → 不定冠词；
  • “想要、必须、去” → 将来时标记；
  • 方向/目标标记 → 不定式标记；
  • 处所结构 → 进行体。
