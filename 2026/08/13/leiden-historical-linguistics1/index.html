Leiden Linguistic Summer School 2025 历史语言学 Day 1 ~ 2

2026.08.13 巴瓦鲁魔法图书馆

授课教师：Niels Schoubben 授课地点：Leiden Linguistic Summer School，Leiden 日期：2025 年 7 月 21 ~ 22 日

第1讲：导论——语言变化与历史语言学

1. 历史语言学研究什么？

历史语言学（historical linguistics / diachronic linguistics）研究语言如何随时间变化，以及我们如何根据现存材料恢复过去的语言状态。它与研究某一时间点语言系统的共时语言学（synchronic linguistics）相对。研究可以针对单一语言的历史，也可以通过比较亲属语言来研究共同祖先；词源学（etymology）只是历史语言学的一部分，核心问题是语言变化的类型、机制、传播方式以及重建方法。

语言可以在几乎所有层面发生变化：

  • 语音/音系（phonetic / phonological change）：发音、音位体系改变。
  • 形态（morphological change）：词形变化、类比、重分析等。
  • 句法（syntactic change）：结构被重新分析并扩展。
  • 词汇（lexical change）：新词、借词、词汇消失。
  • 语义（semantic change）：已有词的意义发生变化。
  • 社会分布（sociolinguistic change）：不同变体在群体中竞争、传播并取代旧形式。

2. 从古英语到现代英语：变化是常态

讲义用四个时期的英语材料展示语言持续变化：

时期 材料 可观察的现象
古英语（Old English） Beowulf 词形变化丰富；词汇、拼写和句法与现代英语差异很大
中古英语（Middle English） Chaucer 大量形态简化已经发生，但仍保存许多现代英语没有的形式
早期现代英语（Early Modern English） Shakespeare 已较容易理解，但代词、动词屈折、否定、比较级和词义仍与今天不同
现代创新变体 当代美国英语材料 ain’t, finna, gimme 等表明现代语言同样处于持续变化中

因此，不能把某一时期的“标准语”看作语言的终点。今天被视为规范的形式，本身也是过去变化的结果；今天被批评为“不规范”的形式，也可能成为未来语言的一部分。

3. 拼写为什么能保存语言历史？

英语中大量“哑音字母（silent letters）”往往反映较早的发音，例如：

  • knife, knee 中的 <k> 原先曾发音；
  • write, wrong 中的 <w> 原先曾发音；
  • light, night 中的 <gh> 对应历史上的喉/软腭擦音；
  • listen, castle 等词中的 <t> 保存了较早阶段的辅音。

这说明拼写往往比发音保守，因此历史拼写和拼写变体可以成为重建过去发音的重要证据。不过，拼写并不等于发音：书写传统、词源拼写、规范化和抄写习惯都可能使文字与实际语音脱节，所以必须与韵律、方言、借词、语音对应等证据结合。

4. Shakespeare 的英语说明了哪些变化？

Shakespeare 与现代英语之间的差异并不只在词汇。例如：

  • Hath not ...? → 现代英语通常使用 does not / has not；
  • Whither 等方向副词逐渐退出一般使用；
  • methinks 等旧结构消失；
  • the most unkindest 表明当时可以出现今天标准语不接受的“双重最高级”；
  • 一些词的意义发生变化，因此即使字形相同也可能造成误读。

语言变化因此不是“单词变了”这么简单，而是语音、形态、句法、词汇和语义同时发生、速度又不完全一致的历史过程。

5. 如何看待“错误”和语言变化？

语言使用者常把新的形式评价为“懒惰”“错误”或“语言退化”，但历史语言学首先把这些现象当作需要解释的数据，而不是先进行价值判断。语言变化具有普遍性和不可避免性；真正需要回答的问题是：

  1. 发生了什么变化？
  2. 变化在什么环境、时间和地区发生？
  3. 它为什么产生？
  4. 它如何从变体传播为新的常规形式？
  5. 我们怎样利用现存证据恢复变化以前的状态？

第2讲：词汇变化——新词、借词与语义变化

词汇变化（lexical change）在本讲中主要分为三类：新词形成（neologism）、借用（borrowing）和语义变化（semantic shift）；此外还要考虑词汇消失（lexical loss）。

1. 新词形成（Neologism）

复合（compounding）

两个或更多词汇基础组合成新词。

  • 中心语在后（head-final）：website, football。
  • 中心语在前（head-initial）：法语 passeport；威尔士语 jwg llaeth “milk jug”。
  • 并列/等位复合（coordinative / copulative / dvandva）：两个成分都是中心语，如荷兰语 zoetzuur “sweet-and-sour”、singer-songwriter。
  • 离心复合（exocentric / bahuvrīhi）：整体所指不等于任何一个内部成分，如 skinhead, forget-me-not。

派生（derivation）

在已有词根或词干上加入构词成分：

  • 前缀（prefixation）：post-modern, ex-husband；
  • 后缀（suffixation）：Trumpian, hypothesise；
  • 中缀（infixation）：fan-fuckin-tastic，英语中较少作为常规派生手段；
  • 零派生/转换（conversion / zero derivation）：形式不变而词类改变，如 text → to text。

其他构词方式

  • 截短（clipping）：omnibus → bus, influenza → flu, mayonnaise → mayo。
  • 拼缀/混成（blending / portmanteau formation）：smoke + fog → smog; breakfast + lunch → brunch; hungry + angry → hangry。
  • 逆构词（back-formation）：说话者把原有词误分析为“词根+词缀”，再反向造出较短形式，如 beggar → beg; self-destruction → self-destruct。

2. 借用（Borrowing）

借用是从另一种语言采用词或其他语言材料。词汇最容易借入，但借用性（borrowability）不是绝对的：核心词汇和形态通常较抗拒借用，但在足够强烈的接触条件下，代词、基本动词、连词、屈折形态甚至音位都可能借入。

直接借词与间接借用

借译（calque / loan translation）不是“借一部分词根再加本族语词缀”，而是用本族语材料逐项翻译外语词的内部结构。讲义例：

  • 希腊语 sym-pátheia “with-suffering” → 拉丁语 com-passiō。

组合形式（combining forms）则是借入古典语言词素后在新语言中重新组合，例如 crypto-zoo-logy 由希腊语来源的多个构词成分组成，但这个整体并不是直接从古希腊语借来的现成词。

音系整合（phonological integration）

借词进入受语（recipient language）后必须适应其音系：

  • 尽量复制（reproduction）源语言发音：英语 genre ← 法语 genre；
  • 适应（adaptation / incorporation）受语音系：土耳其语 kahve ← 阿拉伯语 qahwah。

日语英语借词练习说明：如果受语不允许某些辅音连缀或词尾辅音，就会插入元音、改变辅音、调整音节结构。

形态整合（morphological integration）

借入后通常按受语自己的语法变化：

  • 名词：意大利语 panino/panini → 英语常见 panini/paninis；
  • 动词：借入词根后进入本族语动词屈折系统；
  • 轻动词结构（light verb construction）：英语 shopping → 法语 faire du shopping；法语 danser → 土耳其语 dans etmek。

借用还可能改变音位系统：英语历史上词首 [f] 与 [v] 的分布受到大量借词影响，最终使 /f/ : /v/ 成为明确对立。

3. 语义变化（Semantic Shift）

语义变化是已有词发展出新意义。Meillet 将其来源概括为：

  1. 外部世界变化：技术和社会对象改变，如 phone, car；
  2. 语言内部变化：如英语 meat 早期意义更接近“食物”；
  3. 接触诱发（contact-induced）：一种语言的词义受另一语言语义模式影响。

主要类型

类型 定义 例子
一般化（generalisation / broadening） A 原来只是 B 的一种，后来扩展为 B Latin passer “sparrow” → Spanish pájaro “bird”
特殊化（specialisation / narrowing） A 原本较宽，后来只表示其中一种 B English deer “animal” → “deer”
褒义化（amelioration） 新义社会评价更高 knight “servant” → “knight”
贬义化（pejoration） 新义社会评价更低 Latin puta “girl” → Spanish puta
委婉/避讳（euphemism / taboo avoidance） 用较可接受的表达替代禁忌或不悦表达 rooster 替代 cock 的部分用法
贬称/恶语（dysphemism） 刻意使用较负面的称呼 荷兰语 Spanjaard 的贬称色彩
夸张（hyperbole） 强度不断扩张 terrible, awesome, literally
隐喻（metaphor） 基于相似性 mouse “老鼠” → “鼠标”
转喻（metonymy） 基于现实中的邻接或关联 the White House → 美国行政当局

一个词可以同时经历多种变化，分类的目的不是给每个词贴唯一标签，而是描述语义关系如何变化。

4. 词汇消失（Lexical Loss）

词可能因为以下原因退出语言：

  • 指称对象或社会制度消失，如 churl 原先的社会等级意义；
  • 被新词、借词或新构词替代，如古英语 æþeling 被法语来源的 prince 取代；
  • 同音/同形造成歧义压力，例如一个意义被另一个词替换。
